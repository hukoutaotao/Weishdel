# 部署拖拽悬停预览说明

更新日期：2026-08-25

适用版本：C++17、SFML 2.6.2、MSVC x64 Release

## 1. 功能范围

准备阶段拖拽己方单位时，界面会根据鼠标当前悬停位置提供部署预览。该功能适用于：

- 从备用区拖到己方部署格；
- 将已经部署的己方单位拖到另一个空的己方部署格；
- 其他仍由原有拖拽流程处理的准备阶段单位移动。

预览只针对当前玩家的**空的、可部署的、具有既定路线的部署格**。敌方格、障碍、棋盘外、备用槽、出售区以及已有己方单位的格子不会显示普通部署预览；已有单位的格子继续保留原有合成交互。

## 2. 悬停时的视觉反馈

当鼠标按住单位并悬停在有效部署格上时：

1. 当前部署格叠加半透明黑色遮罩，看起来会变暗；
2. 从当前部署格开始，沿该格对应的既定路线绘制直到敌方守卫格；
3. 路线使用白色半透明虚线表示，避免与“显示路线”按钮控制的彩色调试路线混淆。

当鼠标移出有效部署格、拖拽取消或鼠标释放后，遮罩和白色虚线路线都会消失，棋盘恢复原来的显示状态。

## 3. 与原有路线按钮的关系

原有“显示路线/隐藏路线”按钮仍然有效。拖拽悬停预览期间，预览层会临时替换按钮控制的彩色路线显示，只保留当前目标格对应的白色虚线路线；拖拽结束后，按钮原先的显示状态自动恢复。

## 4. 对核心逻辑的影响

本功能只在 `MatchScreen` 和 `MapRenderer` 中增加拖拽状态判断、目标格识别和绘制层：

- 不新增或修改部署、移动、合成、出售命令；
- 不改变地图路线数据和核心规则校验；
- 不改变释放时原有命令分流；
- 预览失败时不会排队任何核心命令。

因此，该功能属于表现层增强，不需要修改核心游戏逻辑。
