# 自走棋对战系统演示视频录制脚本

日期：2026-08-22

## 1. 文档用途和当前状态

本脚本用于指导第一次录制课程项目演示视频的同学，从发布目录启动程序，连续展示一局对战，并在录制后完成播放、大小和 SHA-256 验收。

当前仅确认本机已经安装以下系统工具，没有安装新软件：

- Xbox Game Bar：7.326.8061.0。
- Windows 截图工具：11.2605.36.0，包含屏幕录制入口。

截至 2026-08-22，演示视频尚未实际录制和完整播放，因此提交材料检查表中的视频项目必须继续保持未勾选。

## 2. 录制方式选择

### 2.1 首选：Windows 截图工具屏幕录制

课程要求展示“从双击 EXE 开始”，因此首选截图工具的屏幕录制功能。它可以先框选包含资源管理器和 1280×720 游戏窗口的区域，再开始录制，能够保留双击启动过程。

操作入口：

1. 在开始菜单搜索并打开“截图工具”。
2. 切换到“录制”或摄像机图标。
3. 点击“新建”。
4. 框选只包含资源管理器和游戏窗口预定位置的区域。
5. 点击“开始”，倒计时结束后再进行双击启动。

### 2.2 备选：Xbox Game Bar

如果截图工具无法正常录制，可在游戏已经启动并获得焦点后按 `Win+G`，确认“捕获”面板可用，再按 `Win+Alt+R` 开始或结束录制。

Game Bar 通常只录制当前应用，可能无法录到资源管理器中的双击过程。因此使用该方案时，应先确认课程是否接受“从游戏窗口出现开始”的视频；若必须看到双击 EXE，应继续使用截图工具或课程指定工具。

## 3. 录制前隐私和环境检查

逐项完成后再开始录制：

1. 关闭聊天软件、邮箱、浏览器账号页、网盘、课程平台和其他可能显示个人信息的窗口。
2. 打开 Windows“勿扰”或关闭通知横幅，避免消息弹窗进入视频。
3. 清空或移走桌面上含姓名、学号、手机号、文件路径或私人照片的图标。
4. 关闭 VS Code 的调试终端、`build/qa-temp` 和三个个人辅助脚本窗口。
5. 只打开项目的 `dist` 文件夹；不要展示 `.git`、构建缓存和故障测试副本。
6. 核对 `dist` 恰好有 10 个文件：1 个 EXE、3 个 SFML DLL、4 个 cfg 和 2 张地图。
7. 将显示缩放和窗口位置调整到能完整看清 1280×720 游戏客户区；不能裁掉右侧按钮、底部备用区或顶部回合信息。
8. 将鼠标指针设置为正常大小并确保可见，录制中不要快速晃动。
9. 预留足够磁盘空间；建议至少保留 2 GB。
10. 先试录 10 秒并回放，确认画面、鼠标和中文文字清晰，再删除试录文件。

## 4. 正式录制动作顺序

建议录制为一个连续视频，不剪切、不加速。每次点击后停留约 1～2 秒，让观看者看清页面和反馈。

### 4.1 启动与帮助页

1. 开始屏幕录制。
2. 在 `dist` 中清楚展示 `AutoChessGame.exe` 和三个 SFML DLL。
3. 双击 `AutoChessGame.exe`。
4. 等待标题为 `AutoChess` 的 1280×720 窗口出现。
5. 在主菜单停留约 2 秒，确保“开始游戏”“帮助”“退出”可见。
6. 点击“帮助”。
7. 缓慢展示帮助页中的购买、刷新、部署、撤回、合成、出售、复活和提前开战说明。
8. 点击“返回主菜单”。

### 4.2 地图、分队和电脑策略

1. 点击“开始游戏”。
2. 在地图选择页停留约 2 秒，再选择任一地图。
3. 在分队选择页停留约 2 秒，再选择任一分队。
4. 在电脑策略页停留约 2 秒，确保“进攻型”“防守型”“路线型”和最终说明文字可见。
5. 选择任一电脑策略，进入准备阶段。

### 4.3 购买、部署和路线

1. 先停留约 2 秒，展示回合、金币、双方守卫、倒计时和六槽商店。
2. 点击一个金币足够购买的商品。
3. 停留约 2 秒，展示金币减少且单位进入左下方备用区。
4. 在备用区按住该单位，用鼠标拖到一个合法的蓝色部署格后松开。
5. 停留约 2 秒，展示单位已经位于棋盘部署区。
6. 点击“显示路线”，保持路线可见约 3 秒。
7. 再点击“隐藏路线”，证明按钮可以切换且不改变单位状态。
8. 如果金币和时间允许，可再购买并部署一个单位；不要为了演示合成而反复刷新导致金币不足。

### 4.4 战斗、技能状态、暂停和继续

1. 电脑部署完成后点击“提前开始战斗”；若按钮尚不可用，等待电脑完成部署后再点击。
2. 战斗开始后停留约 5 秒，展示单位自动移动、索敌和攻击。
3. 点击一个仍存活的己方单位，展示右侧名称、等级、生命、技力和目标信息。
4. 将鼠标移动到技能按钮附近，清楚展示“技能未就绪”或“释放技能”状态。
5. 如果按钮已经变为“释放技能”，可点击一次并展示结果；如果仍未就绪，不要连续点击。
6. 点击右上角“暂停”。
7. 在“游戏已暂停”画面停留至少 3 秒，确保“继续游戏”“重新开始”“返回主菜单”可见。
8. 点击“继续游戏”。
9. 再停留至少 5 秒，展示单位继续移动、攻击且倒计时继续变化。

### 4.5 回合结算和结果页

1. 不要在中途返回主菜单，也不要关闭窗口。
2. 每回合结束时保持结算页完整可见，展示双方守卫伤害、死亡、到达守卫和存活数量。
3. 等待程序自动进入下一阶段，并按需要继续购买、部署和提前开战。
4. 正式配置最多 3 回合，持续录制直到出现“你获胜了”“电脑获胜”或“本局平局”。
5. 在结果页停留至少 5 秒，确保完成回合数、双方守卫值、“再来一局”和“返回主菜单”全部可见。
6. 点击“返回主菜单”，停留约 2 秒。
7. 正常关闭游戏窗口。
8. 停止屏幕录制并保存文件。

## 5. 文件命名和保存位置

建议文件名使用：`AutoChess-demo-2026-08-22.mp4`。

视频应保存在最终提交材料目录，不要放进 `build`、`build/qa-temp`、系统临时目录或个人聊天软件接收目录。若课程平台规定了文件名、格式或大小，以课程平台要求为准。

## 6. 录制后验收

录制完成后必须逐项执行：

1. 关闭游戏和录屏工具，重新从文件管理器打开视频。
2. 从第 0 秒连续播放到结尾，不能只拖动进度条抽查。
3. 确认视频开头包含双击 EXE，结尾包含结果页和正常返回主菜单。
4. 确认帮助、路线、购买、部署、战斗、技能按钮状态、暂停、继续和结果页均清楚可辨。
5. 确认没有个人通知、账号、聊天内容、私人文件名或故障测试目录进入画面。
6. 在文件属性中记录准确时长和字节大小。
7. 使用另一个可用播放器再完整播放一次，确认音视频文件没有损坏；本项目没有游戏音效，视频无游戏声音不算故障。
8. 计算 SHA-256，并把文件名、时长、字节数和哈希登记到提交材料检查表或最终提交记录。

```powershell
# 作用：此命令读取最终视频的实际字节数和 SHA-256，供提交前登记和复核。
$video = 'D:\最终提交材料\AutoChess-demo-2026-08-22.mp4'
Get-Item -LiteralPath $video | Select-Object Name, Length, LastWriteTime
Get-FileHash -LiteralPath $video -Algorithm SHA256
```

只有在“文件存在、完整播放通过、内容覆盖要求、时长和大小已记录、SHA-256 已计算”全部满足后，才能勾选视频相关检查项。

## 7. 失败时的明确处理

| 现象 | 处理方式 |
|---|---|
| 截图工具没有“录制”按钮 | 改用 Xbox Game Bar；如果课程必须展示双击过程，联系教师确认可接受形式，不要虚构已录制。 |
| Game Bar 提示当前功能不可用 | 返回截图工具，或检查 Windows 设置中的游戏录制功能；不要安装来源不明的录屏软件。 |
| 视频只录到黑屏 | 先关闭录制，改为窗口化 1280×720，并用 10 秒试录确认后重新录制整局。 |
| 游戏窗口被裁切 | 停止录制，重新框选包含完整窗口的区域；不能继续使用缺少右侧或底部界面的录像。 |
| 中途出现个人通知 | 删除该次录像，开启勿扰后从双击 EXE 重新录制。 |
| 没有到达结果页 | 该录像不算完整一局，应重新录制或继续录到结果页后再验收。 |
| 视频无法从头播放到结尾 | 删除损坏文件，确认磁盘空间后重新录制。 |
| 文件超过课程平台限制 | 先查看平台允许的格式和大小；未经教师允许不要通过删除关键过程来缩短视频。 |
