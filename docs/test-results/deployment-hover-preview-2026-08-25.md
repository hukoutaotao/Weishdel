## 3. 本次功能静态验收

- `MatchScreen` 只在准备阶段拖拽活动时计算悬停预览。
- 预览只接受当前玩家的空 `A` 方部署格，并要求存在从该格开始的 `A` 方路线。
- 鼠标移出棋盘或无效格时清空预览状态。
- 鼠标释放前不提交核心命令；释放时沿原有部署、合成、备用区和出售分流处理。
- `MapRenderer` 在预览存在时绘制半透明黑色遮罩和白色虚线路线，并在预览结束后恢复原路线按钮状态。
- 本次实现没有修改 `src/core` 中的规则和命令逻辑。

## 4. 图形界面验收说明

当前验证环境可以完成编译和自动化测试，但未进行需要人工操作窗口的逐项鼠标验收。建议在本地启动 `dist/AutoChessGame.exe` 后按以下顺序检查：

1. 从备用区拖到己方空部署格：目标格变暗并出现白色虚线路线，释放后消失。
2. 拖到敌方格、障碍、备用区或出售区：预览消失，原有操作保持不变。
3. 拖到已有己方单位：不出现普通部署预览，合成交互保持不变。
4. 已部署单位拖到另一个空部署格：出现相同预览。
5. 先打开“显示路线”，再拖拽：拖拽期间临时显示当前白色虚线路线，释放后恢复彩色路线。
6. 至少在 `map_01`、`map_02`、`map_03` 和 `map_04` 各检查一次路线终点和转弯显示。
