# 自走棋对战系统使用说明

更新日期：2026-08-25

适用版本：C++17、SFML 2.6.2、MSVC x64 Release

## 1. 文档用途

本说明面向第一次运行、演示或重新构建本项目的同学。若只是验收成品，直接从 `dist` 运行即可，不需要安装 Visual Studio、CMake、Ninja 或 SFML；只有重新编译源码时才需要开发环境。

## 2. 发布目录必须具备的文件

双击运行前，先打开项目根目录下的 `dist`。目录中应正好有 12 个文件：

```text
# 作用：此目录树用于核对发布程序、三个 SFML 动态库和八个数据文件是否齐全。
dist/
├─ AutoChessGame.exe
├─ sfml-graphics-2.dll
├─ sfml-window-2.dll
├─ sfml-system-2.dll
└─ data/
   ├─ game.cfg
   ├─ units.cfg
   ├─ skills.cfg
   ├─ factions.cfg
   └─ maps/
      ├─ map_01.map
      ├─ map_02.map
      ├─ map_03.map
      └─ map_04.map
```

如果 EXE、任一 DLL 或 `data` 内文件缺失，不要从开发目录随意复制单个文件；应按第 5 节重新生成整个 `dist`。

## 3. 从双击程序到完成一局

### 3.1 启动和查看帮助

1. 双击 `dist/AutoChessGame.exe`。
2. 验收现象：出现标题为 `AutoChess` 的 1280×720 窗口，主菜单显示“开始游戏”“帮助”“退出”。
3. 第一次使用先点击“帮助”，阅读购买、刷新、部署、撤回、合成、出售、复活和提前开战说明。
4. 点击“返回主菜单”。

### 3.2 选择对局内容

1. 点击“开始游戏”。
2. 在“选择地图”页选择“对称双路训练场”、“多路线峡谷”或“中心对称三路要塞”。
3. 在“选择分队”页选择“坚壁分队”“突击分队”或“行军分队”。
4. 在“选择电脑策略”页选择“进攻型”“防守型”或“路线型”。
5. 验收现象：进入“准备阶段”，顶部显示第几回合、金币、双方守卫和剩余秒数；右侧显示六槽商店。

### 3.3 准备阶段操作

1. **购买单位**：点击右侧任一可购买商品。成功后金币减少，单位出现在左下方“备用区”。
2. **部署单位**：在备用区按住鼠标左键，把单位拖到棋盘蓝色部署格后松开。
3. **撤回备用区**：把已部署单位拖回任一空的备用槽。
4. **重新部署**：把已部署单位拖到另一个合法且未占用的蓝色部署格。
5. **合成升级**：把一个单位拖到另一个“类型相同、等级相同”的己方单位上；满足规则时自动合成，最高三级。
6. **出售单位**：把备用区或部署区单位拖到右下方“出售区（拖入出售）”；出售立即生效。
7. **刷新商店**：点击“刷新商店 2 金币”；金币不足时界面会显示失败原因，状态不会被破坏。
8. **查看路线**：点击“显示路线”，再次点击“隐藏路线”；该按钮只改变显示，不改变规则。
9. **复活死亡单位**：后续回合出现死亡单位时，切换到“死亡列表”页签，点击对应“点击复活”按钮；金币不足或备用区已满时会被规则层拒绝。
10. **开始战斗**：电脑部署完成后点击“提前开始战斗”，也可以等待 45 秒准备倒计时归零。

建议第一次演示至少完成“购买一个单位—拖到蓝色部署格—显示路线—提前开始战斗”四个动作，这样能直观看到核心操作闭环。

### 3.4 战斗、暂停和技能

1. 战斗开始后，单位按固定步长自动移动、索敌、攻击、治疗和结算守卫伤害。
2. 点击一个仍存活的己方单位，右侧会显示名称、等级、生命、技力和当前目标。
3. 当按钮从“技能未就绪”变为“释放技能”时点击它；按钮未就绪时不能提交技能命令。
4. 点击右上角“暂停”，验收画面显示“游戏已暂停”。暂停期间只能选择“继续游戏”“重新开始”或“返回主菜单”。
5. 点击“继续游戏”，验收战斗单位继续移动、攻击，倒计时继续减少。
6. 每回合战斗结束后，结算页显示双方守卫伤害以及死亡、到达守卫和存活数量；约 2 秒后自动进入下一阶段。

### 3.5 对局结束

1. 正式配置最多进行 3 回合；任一方守卫归零时也可提前结束。
2. 结果页显示“你获胜了”“电脑获胜”或“本局平局”，并显示完成回合数与双方守卫值。
3. 点击“再来一局”会回到地图选择；点击“返回主菜单”会回到主菜单。
4. 完整演示以到达结果页并能执行一次“再来一局”或“返回主菜单”为完成标准。

## 4. 在 VS Code 中运行现有 Release 程序

1. 用 VS Code 打开项目根目录。
2. 确认已经完成第 5 节的 Release 构建。
3. 打开“运行和调试”，选择 `AutoChessGame - Release` 后启动。
4. 若要调试自动测试，选择 `AutoChessTests - Release`。
5. `.vscode/launch.json` 只负责启动，首次构建仍需在终端执行 CMake 命令。

## 5. 从源码重新构建、测试和生成发布目录

### 5.1 开发环境前提

- Windows x64。
- MSVC，并在 **x64 Developer Command Prompt/PowerShell** 环境中执行命令；先运行 `cl` 应能找到编译器。
- CMake 3.25 或更高版本。
- Ninja。
- 项目自带 `third_party/SFML` 中的 SFML 2.6.2；不需要在线下载新库。

### 5.2 干净配置并构建 Release

```powershell
# 作用：此命令组在 MSVC x64 开发者终端中重新配置并编译 Release 游戏与测试程序。
Set-Location D:\1
cmake --preset msvc-release --fresh
cmake --build --preset msvc-release
```

验收结果：命令退出码为 0，生成 `build/msvc-release/AutoChessGame.exe`、`build/msvc-release/AutoChessTests.exe` 和 `build/msvc-release/AutoChessCore.lib`。

### 5.3 运行完整自动测试

```powershell
# 作用：此命令运行 Release 自动测试，最终必须看到 422 PASS、0 FAIL。
Set-Location D:\1
& .\build\msvc-release\AutoChessTests.exe
```

验收结果：进程退出码为 0；36 组 AI MATRIX 全部 `command_failures=0`、`rounds=3`。

### 5.4 重新组装独立发布目录

```powershell
# 作用：此命令调用项目已有的 AutoChessDist 目标，清空并重新生成完整 dist。
Set-Location D:\1
cmake --build --preset msvc-release --target AutoChessDist
```

验收结果：`dist` 中只有第 2 节列出的 12 个文件，八个数据文件与源码 `data` 内容一致。

### 5.5 从项目外工作目录验证发布程序

```powershell
# 作用：此命令把当前工作目录切到项目外，再启动 dist 中的 EXE，以验证程序不依赖源码工作目录。
Set-Location D:\
& D:\1\dist\AutoChessGame.exe
```

验收结果：主菜单窗口能够创建并正常退出；程序优先读取 EXE 旁的 `data`。

## 6. 常见问题与处理

| 现象 | 可检查原因 | 明确处理方式 |
|---|---|---|
| 双击后提示缺少 `sfml-*.dll`，或进程返回 `0xC0000135` | EXE 旁缺少 SFML Release DLL | 不要下载来源不明 DLL；执行 `AutoChessDist` 目标重新生成整个发布目录。 |
| 提示找不到 `game.cfg`、地图或其他数据 | `dist/data` 不完整或目录层次改变 | 对照第 2 节恢复目录；不要把八个数据文件放到 EXE 同级。 |
| 提示配置字段非法、范围越界或引用不存在 | 正式 cfg/map 被手工改动 | 从 Git 恢复 `data`，再重新生成 `dist`；不要在演示前临时改数值。 |
| 提示中文字体加载失败 | Windows 可用中文字体缺失或系统字体异常 | 在正常 Windows 中文环境运行；本项目不随发布包分发字体。 |
| 按钮显示失败原因 | 金币不足、备用区满、部署格非法、格子占用或规则不满足 | 阅读界面三秒提示，调整金币、槽位、目标格或单位类型/等级后重试。 |
| 构建时提示不是 MSVC | 未进入 x64 Developer 环境 | 关闭当前终端，从 Visual Studio 的 x64 Developer Command Prompt/PowerShell 重新打开项目。 |
| CMake 找不到 SFML 2.6.2 | `third_party/SFML` 缺失或被移动 | 恢复仓库原有 SFML 目录；不要自行引入其他版本替代。 |

## 7. 不属于本项目范围的功能

本课程项目不实现联网、存档、音效、精细动作动画、装备、复杂控制效果或单位碰撞。验收时不要把这些未列入总计划的内容当作启动或完整对局的前提。
